# Chapter 2 Tables 2-4–2-6 — Keyboard Area: Touchpad, Status Lights (Caps Lock/Privacy/Mute) & Special Keys (Sure View, Camera Privacy Key & Fingerprint Reader) (PDF p.14–18 · Doc p.8–12)

This section details the keyboard area, touchpad controls, indicator lights, and special operational keys for the HP Dragonfly Folio 13.5 inch G3 2-in-1 Notebook PC (Reference: PDF p.14–18, Doc p.8–12).

---

## 1. Keyboard Area Overview

- **Regional Layouts**: Keyboards can vary depending on the language/country configuration.
- **Operational Modes Notice**: The keyboard, including the function keys and power key, is automatically disabled in stand, tent, and tablet modes. To re-enable the keyboard and power key, switch the computer back to clamshell mode.

---

## 2. Touchpad Settings and Components

### Adjusting Touchpad Settings and Enabling Touchpad
1. Select the Search icon in the taskbar, type `touchpad settings` in the search box, and press Enter.
2. Choose the desired setting.
3. **Turning on the touchpad**:
   - Using an external mouse: Click the Touchpad toggle button.
   - Without an external mouse: Press the `Tab` key repeatedly until the pointer rests on the Touchpad toggle button, then press the `Spacebar` to select and toggle the setting.

### Table 2-4: Touchpad Components and Descriptions
| Item | Component | Description |
| :--- | :--- | :--- |
| (1) | Touchpad zone | Reads finger gestures to move the pointer or activate items on the screen. |
| (2) | Left touchpad button | Functions like the left button on an external mouse. |
| (3) | Right touchpad button | Functions like the right button on an external mouse. |

## 3. Lights

### Table 2-5: Lights and Descriptions
| Item | Component | State & Description |
| :--- | :--- | :--- |
| (1) | Caps lock light | **On**: Caps lock is enabled, switching input to all uppercase characters. |
| (2) | Privacy key light | **On**: HP Sure View privacy screen is active, helping prevent side-angle viewing. |
| (3) | Mute light | • **On**: Computer audio output is muted.<br>• **Off**: Computer audio output is active. |
| (4) | Microphone mute light | • **On**: Microphone is disabled/muted.<br>• **Off**: Microphone is active. |
| (5) | Camera key light | • **On**: The camera is turned off via the electronic privacy shutter.<br>• **Off**: The camera is turned on. (Ontology/troubleshooting reference: `TS-DFG3-005`) |
| (6) | Power light | • **On**: The computer is on.<br>• **Blinking (select products only)**: The computer is in the Sleep power-saving state; power to the display and unnecessary components is cut.<br>• **Off**: Depending on the model, the system is turned off, in Hibernation, or in Sleep mode. |
| (7) | Fn lock light | **On**: The `fn` key lock state is engaged. |

## 4. Special Keys

### Table 2-6: Special Keys and Descriptions
| Item | Component | Description |
| :--- | :--- | :--- |
| (1) | esc key | Displays system information when pressed in combination with the `fn` key. |
| (2) | fn key | Executes frequently used system functions when pressed in combination with another key (hot keys). |
| (3) | Windows key | Opens the Start menu. Pressing the key again closes the Start menu. |
| (4) | Action keys | Execute dedicated system functions (F1–F12). Includes the electronic camera privacy key (`F12` / special key `(4)`) and Sure View controls. If experiencing shutter actuation or camera detection issues, refer to troubleshooting guideline `TS-DFG3-005`. |
| (5) | Power key | • **Computer off**: Press briefly to turn on the computer.<br>• **Computer on**: Press briefly to initiate the Sleep state.<br>• **Sleep state**: Press briefly to resume operations from Sleep (select products only).<br>• **Hibernation state**: Press briefly to exit Hibernation.<br><br>**IMPORTANT**: Pressing and holding down the power key results in the loss of unsaved information.<br>If the computer becomes non-responsive and normal shutdown fails, press and hold the power key for **at least 4 seconds** to force shutdown.<br>To manage power behaviors, right-click the Power icon on the taskbar and select **Power and sleep settings**. |
