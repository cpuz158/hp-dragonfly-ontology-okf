# 제2장 표 2-4~2-6 — 키보드 영역: 터치패드 · 상태 표시등(Caps Lock/프라이버시/음소거) · 특수 키(Sure View·카메라 프라이버시 키·지문인식기) (PDF p.14–18 · Doc p.8–12)

이 문서는 HP Dragonfly Folio 13.5 inch G3 2-in-1 Notebook PC의 키보드 영역, 터치패드, 상태 표시등 및 특수 키의 구성 요소와 동작 방식을 다룹니다 (참조: PDF p.14–18, Doc p.8–12).

---

## 1. 키보드 영역 개요 (Keyboard Area Overview)

- **언어별 차이**: 키보드 레이아웃은 출시 언어/국가에 따라 다를 수 있습니다.
- **모드별 비활성화 주의사항**: 스탠드(Stand), 텐트(Tent), 태블릿(Tablet) 모드에서는 기능 키와 전원 키를 포함한 전체 키보드 입력이 자동으로 비활성화됩니다. 키보드와 전원 키를 다시 사용하려면 컴퓨터를 클램쉘(Clamshell, 일반 노트북) 모드로 전환해야 합니다.

---

## 2. 터치패드 설정 및 구성 요소 (Touchpad)

### 터치패드 설정 및 켜기 절차
1. 작업 표시줄의 검색 아이콘을 선택하고 검색창에 `터치패드 설정` (touchpad settings)을 입력한 후 Enter 키를 누릅니다.
2. 원하는 설정을 조정합니다.
3. **터치패드 켜기**:
   - 외장 마우스가 연결되어 있는 경우: 터치패드 켜기/끄기 단추를 클릭합니다.
   - 외장 마우스가 없는 경우: 포인터가 터치패드 단추에 위치할 때까지 `Tab` 키를 반복해서 누른 다음 `스페이스바(Spacebar)`를 눌러 단추를 선택합니다.

### 표 2-4: 터치패드 구성 요소 (Touchpad Components)
| 번호 | 구성 요소 | 설명 |
| :--- | :--- | :--- |
| (1) | 터치패드 영역 (Touchpad zone) | 손가락 제스처를 감지하여 포인터를 이동하거나 화면의 항목을 실행합니다. |
| (2) | 좌측 터치패드 버튼 (Left touchpad button) | 외장 마우스의 왼쪽 버튼과 동일하게 작동합니다. |
| (3) | 우측 터치패드 버튼 (Right touchpad button) | 외장 마우스의 오른쪽 버튼과 동일하게 작동합니다. |

## 3. 표시등 (Lights)

키보드 및 주변부에 위치한 주요 상태 표시등의 동작 상태는 다음과 같습니다.

### 표 2-5: 표시등 및 설명 (Lights and Descriptions)
| 번호 | 표시등 명칭 | 상태 및 설명 |
| :--- | :--- | :--- |
| (1) | Caps lock 표시등 | **점등(On)**: Caps lock이 활성화되어 모든 영문 입력이 대문자로 전환됩니다. |
| (2) | 프라이버시 키 표시등 (Privacy key light) | **점등(On)**: 프라이버시 스크린(HP Sure View)이 켜져 측면 시야각에서의 화면 확인을 차단합니다. |
| (3) | 음소거 표시등 (Mute light) | • **점등(On)**: 컴퓨터 스피커 사운드가 꺼져 있습니다(음소거).<br>• **소등(Off)**: 컴퓨터 사운드가 켜져 있습니다. |
| (4) | 마이크 음소거 표시등 (Microphone mute light) | • **점등(On)**: 마이크가 꺼져 있습니다.<br>• **소등(Off)**: 마이크가 켜져 있습니다. |
| (5) | 카메라 키 표시등 (Camera key light) | • **점등(On)**: 전자식 카메라 프라이버시 셔터가 작동하여 카메라가 꺼져 있습니다.<br>• **소등(Off)**: 카메라가 켜져 있습니다. (문제 해결 링크: `TS-DFG3-005` 참조) |
| (6) | 전원 표시등 (Power light) | • **점등(On)**: 컴퓨터가 켜져 있습니다.<br>• **깜박임(Blinking, 일부 제품)**: 컴퓨터가 절전(Sleep) 상태입니다. 화면 및 불필요한 부품 전원을 차단합니다.<br>• **소등(Off)**: 모델에 따라 전원이 완전히 꺼졌거나 최대 절전 모드(Hibernation) 또는 절전 상태입니다. |
| (7) | Fn lock 표시등 | **점등(On)**: Fn 키가 잠금 상태로 설정되어 있습니다. |

## 4. 특수 키 (Special Keys)

### 표 2-6: 특수 키 및 설명 (Special Keys and Descriptions)
| 번호 | 특수 키 명칭 | 설명 |
| :--- | :--- | :--- |
| (1) | esc 키 | `fn` 키와 함께 누르면 시스템 정보(System Information)가 화면에 표시됩니다. |
| (2) | fn 키 | 다른 키와 조합하여 누르면 자주 사용되는 시스템 기능(핫키)을 실행합니다. |
| (3) | Windows 키 | 시작 메뉴(Start menu)를 엽니다. 다시 누르면 시작 메뉴가 닫힙니다. |
| (4) | 액션 키 (Action keys) | F1~F12 등에 매핑되어 자주 사용하는 시스템 기능을 바로 실행합니다. 전자식 카메라 프라이버시 키(`F12` / 특수 키 `(4)`) 및 Sure View 조작을 포함합니다. 카메라 오작동 또는 토글 불가 시 `TS-DFG3-005`를 참조하십시오. |
| (5) | 전원 키 (Power key) | • **전원 꺼짐 상태**: 짧게 누르면 전원이 켜집니다.<br>• **전원 켜짐 상태**: 짧게 누르면 절전 모드로 진입합니다.<br>• **절전 상태**: 짧게 누르면 절전 모드를 종료합니다(일부 모델).<br>• **최대 절전 모드**: 짧게 누르면 최대 절전 모드를 종료합니다.<br><br>**중요(IMPORTANT)**: 전원 키를 길게 누르면 저장되지 않은 데이터가 손실될 수 있습니다.<br>시스템이 응답하지 않고 정상적인 종료가 불가능한 경우, 전원 키를 **최소 4초 이상** 길게 눌러 강제 종료할 수 있습니다.<br>전원 설정을 변경하려면 작업 표시줄의 전원 아이콘을 우클릭한 후 **전원 및 절전 설정**을 선택하십시오. |
